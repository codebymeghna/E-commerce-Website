# Veloce E-commerce Website

A responsive e-commerce website built using HTML, CSS, Tailwind CSS, and JavaScript.

## Features
- Responsive Navbar
- Hero Slider
- Product Catalog
- Product Modal
- Shopping Cart
- Wishlist
- Search Functionality
- Category Filter
- Pagination
- Contact Form
- Toast Notifications
- Account Dropdown

## Technologies Used
- HTML5
- CSS3
- Tailwind CSS
- JavaScript
